🤖 AI-Tutor
AI-Tutor is an interactive educational platform designed to bridge the gap between complex information and student understanding. By leveraging AI-assisted learning, the application provides instant, step-by-step explanations for code, logic, and general academic problems, making learning more accessible and engaging.

🌟 Key Features
  -Instant Explanations: Paste snippets of code or complex text and receive a comprehensive breakdown in seconds.

  -Multi-Language Support: Optimized for various programming languages including JavaScript and Python.

  -Interactive UI: A modern, responsive dashboard featuring smooth animations and a mobile-first design.

  -Dark/Light Mode: Seamless theme switching to accommodate user preference and reduce eye strain.

  -Example Library: Built-in examples to help users quickly understand how to interact with the AI logic.

🛠️ Technology Stack
  -Frontend: HTML5, Vanilla JavaScript

  -Styling: Tailwind CSS (Utility-first CSS framework)

  -Icons: Heroicons

  -Animations: Custom CSS transitions and animations for a fluid UX.

🚀 Getting Started
Follow these steps to get a local copy of the project up and running.

Prerequisites
You only need a modern web browser (Chrome, Firefox, Edge, or Safari).

Installation
1.Clone the repository:
git-clone https://github.com/PARVDESAI1501/AI-tutor.git

2.Navigate to the project folder:
cd AI-tutor

3.Launch the app:
Simply open index.html in your browser.

🧠 How It Works
1.Input: The user enters a programming problem or a block of code into the input area.

2.Processing: The app triggers an "AI Simulation" logic that analyzes the input structure.

3.Output: The system returns a categorized explanation, including logic breakdown, potential optimizations, and conceptual teaching.
